# Fall 2026 involvement-fair QR

The primary production domain is `https://unlvmountainclub.com`. The shorter
`https://unlvmountain.club` domain redirects to it.

Regenerate both medium- and quartile-error-correction candidates with:

```sh
pnpm generate:fair-qr https://unlvmountainclub.com
```

The encoded destination is:

```text
https://unlvmountainclub.com/welcome?source=fall-2026-involvement-fair
```

The command creates 2400-pixel PNG and SVG versions for both M and Q. Choose
the final print asset only after testing the actual sign under booth lighting,
glare, angles, slow cellular service, Discord installed/not installed, and a
representative mix of older and newer iOS and Android devices. Print the clean
`/welcome` URL and the Discord invite below the code as readable fallbacks.
